# 平假名發音頁 46 字錄音

本次從 main `54fb8d7`（已合併 PR #319）建立。僅將「平假名發音頁」改為 46 段錄音：保留 PR #318 的五份 WAV 原始位元組，新增其餘 41 份；不新增濁音、半濁音或拗音。

## 對應依據與切分

使用者明確確認原始錄音從「あ」開始，完全依發音頁 46 字順序各讀一次，沒有漏字、重錄或插入其他聲音。音訊分析偵測到 46 個由明顯停頓分隔的發聲區間，並逐段檢視波形及切點。未確認片段：**0**。

曾以本機 Whisper base／small 作補充檢查；對單音的輸出不穩定，不能作為逐字辨識的唯一證據。本次對應依據為錄音提供者的完整順序確認，加上 46 個分隔區間、波形檢查及來源樣本驗證，未以自動辨識錯字覆蓋假名或猜測重排。「を」位於已確認的第 45 段，實際讀音與「お」同為 /o/。

## 格式與音量

- 全部為 48 kHz、單聲道、16-bit PCM WAV。五母音的原有切點、檔名、位元組及 SHA-256 全數保留。
- 新增 41 段在 −35 dB 發聲區間前保留約 250 ms、後保留約 350 ms，切點四捨五入到毫秒；逐段首尾 50 ms 低音量區、相鄰區間不重疊及波形檢查皆通過。
- 新片段採單一固定增益：以 10 ms 來源音框、RMS > 0.015 的活躍音框計算，調整至 −24 dBFS 活躍 RMS，約為原五母音的中位音量。增益範圍 -8.9121 至 4.3106 dB；所有檔案峰值低於 −3 dBFS，沒有削波。
- 原五母音為遵守保留要求，維持既有音量差異。新增片段只乘固定增益，沒有壓縮、降噪、淡入淡出、變速或變調。
- manifest 2.0 記錄來源雜湊、46 組起訖與輸出雜湊、固定增益、原五段保留標記及各頁使用範圍。

## 程式範圍

- 新增發音頁專用 `hiraganaChartAudio.js?v=1.0`，有獨立 46 字對照及 HTML Audio controller；不建立或呼叫 TTS。發音頁 `hiragana.js` 升為 1.3。
- 點擊在原事件堆疊直接 `Audio.play()`，不另加固定 1 秒等待；切換字、重播、返回首頁及 pagehide 會停止前段，舊事件／Promise 不覆蓋新狀態，載入錯誤可重試。
- 聽音練習仍使用既有 `hiraganaAudio.js`：あ／い／う／え／お 五段 WAV，其餘 41 字 TTS。新增的 41 段不會被該對照表解析。
- `japanese/hiraganaListening.js`、`japanese/hiraganaAudio.js`、共用 `script.js` 與其版本皆未修改。一般日文聽力練習、聽力測驗及 JLPT 播放來源與 1 秒準備保持原狀。

## 驗證

新增 `node scripts/check-hiragana-chart-audio.js` 檢查 46 字順序、檔名唯一性、RIFF 完整性、格式、長度、雜湊、原五段雜湊、切點與峰值、音量增益、僅使用 HTML Audio、同步播放、停止／重播、過期事件、錯誤及未支援假名拒播。

來源樣本驗證：

```sh
python3 scripts/verify-hiragana-recording-source.py --source /path/to/original.m4a
```

此腳本驗證來源 SHA-256，再解碼一次逐段套用 manifest 的時間範圍與固定增益；46 份 WAV 的每個 PCM 樣本與來源計算值完全相同。需要 ffmpeg，無須 ASR 模型或額外 Python 套件。

已通過 16 項 Node 檢查：新增 chart-audio，以及 hiragana-ios-tts、hiragana-audio、hiragana-listening、Japanese main-entry、view-isolation、一般 listening audio-start／menu／state-isolation／view-isolation／sentence-final／practice-shuffle、JLPT 18A-1／2／3／4。既有 iOS TTS 測試改在聽音練習逐一驗證 41 字，保留原 999／1000 ms、解鎖、取消、錯誤與完成事件覆蓋；發音頁則驗證 46 字皆為錄音。

變更中的產品 JavaScript 語法檢查、`git diff --check` 及三份聽力來源檔對 main 無差異檢查皆通過。

Playwright／Chromium 154.0.8037.57 桌面與 428×926 手機尺寸（iPhone 使用者代理）均通過：

- 在沒有可用日文 TTS 語音的條件下，46 個按鈕逐字使用真實 WAV，核對每個 URL、duration 與 ended 狀態；發音頁 TTS 呼叫為 0。
- 重播、快速換字、舊完成事件、返回首頁及 pagehide 皆停止／隔離舊播放；HTTP 404 清除播放樣式，恢復資源後重試成功。
- 聽音練習走完 46 題並進入第 47 題；母音題只取原五份 WAV，抽查 か／を／ん 仍使用 TTS，不讀新增錄音。
- 一般日文聽力練習與測驗使用原 TTS，練習可重播，測驗仍維持每題一次。
- 兩種模式皆沒有未捕捉的頁面 JavaScript 錯誤。TTS 使用模擬 provider；WAV 使用真實 HTML Audio 解碼播放。
